# Yoga Flow Player

요가 수업 중 음악을 끊김 없이 전환하는 웹 플레이어입니다. 설치 없이 브라우저에서 `index.html` 하나로 동작합니다.

## 주요 기능
- **부드러운 곡 전환** — 두 데크 크로스페이드(기본 8초), 곡 끝나기 전 자동 전환
- **부드러운 재생·멈춤**, 서서히 끄기
- **싱잉볼** — 소리 파일 없이 합성 (싱잉볼·차임·팅샤, 약 30초 울림), 울릴 때 음악 자동 낮춤
- **사바아사나 타이머** — 끝나면 싱잉볼 3번
- **배경 소리 믹서** — 빗소리, 텐트·지붕 빗소리, 파도, 시냇물(원근감), 바람, 모닥불, 새소리, 풀벌레, 개구리, 물방울, 풍경, 에밀레종, 싱잉볼 명상, 432Hz·528Hz, 내 파일
  - 미리 만든 믹스 8종 + 내 믹스 저장
  - 끄기 예약 (10~90분 뒤 30초 동안 서서히 끔)
- **수업별 곡 목록 저장** (브라우저 IndexedDB), 곡별 볼륨·시작 위치·반복
- **수업 모드** — 큰 버튼 전체 화면, 재생 중 화면 꺼짐 방지

## 단축키
| 키 | 동작 |
|---|---|
| Space | 재생·멈춤 (부드럽게) |
| N / → | 다음 곡 전환 |
| ← | 이전 곡 |
| F | 서서히 끄기 |
| B | 싱잉볼 |
| S | 사바아사나 타이머 |
| A | 배경 소리 켜기·끄기 |
| ↑ ↓ | 볼륨 |
| Z | 수업 모드 |

## 참고
- 곡은 사용하는 브라우저(기기)마다 따로 저장됩니다. 서버로 전송되지 않습니다.
- Chrome / Edge 최신 버전 권장.
