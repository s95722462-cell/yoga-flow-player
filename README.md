# Yoga Flow Player

요가 수업 중 음악을 끊김 없이 전환하는 웹 플레이어입니다. 설치 없이 브라우저에서 `index.html` 하나로 동작합니다.

## 주요 기능
- **부드러운 곡 전환** — 두 데크 크로스페이드(기본 8초), 곡 끝나기 전 자동 전환
- **부드러운 재생·멈춤**, 서서히 끄기
- **파형 표시** — 곡을 처음 재생할 때 한 번 분석해 저장, 누르면 그 위치로 이동
- **큐 버튼 4개** — 곡마다 위치 저장(빈 칸 누름) → 누르면 그 위치로 부드럽게 이동, 길게 누르면 다시 저장, ⚙에서 지우기
- **싱잉볼** — 소리 파일 없이 합성 (싱잉볼·차임·팅샤, 약 30초 울림), 울릴 때 음악 자동 낮춤
- **사바아사나 타이머** — 끝나면 싱잉볼 3번
- **배경 소리 믹서** — 합성 소리 27종(빗소리, 파도, 시냇물, 천둥, 폭포, 목탁, 소쩍새, 고래, 심장 박동, 432Hz 등) + 내 파일
  - 미리 만든 믹스 14종 + 내 믹스 저장
  - 끄기 예약 (10~90분 / 직접 입력 / 시각 지정, 30초 동안 서서히 끔)
- **모닝콜** — 잠들기 소리 → 밤새 아주 작게 → 해 뜨듯 커지는 깨우기 → 울림·5분 더
- **사용 설명서**(앱 안 ? 설명서) + 처음 열 때 한 번 ‘처음 사용’ 안내
- **타임라인 편집** — 곡 ⚙에서 전체 파형의 손잡이를 끌어 시작·끝 위치(앞뒤 자르기), 곡마다 다음 곡 전환 시간(0~30초, 빈칸 = 수업 기본). 자동 다음 곡·반복이 그대로 따름, ‘끝 부분 듣기’로 확인
- **백업·복원** — 💾 백업: 수업(하나/전부)+설정을 .json 파일로 저장, 작은 음원(파일당 20MB·전체 150MB)은 선택해서 함께. 불러오면 새 수업으로 추가, 빠진 음원은 이름으로 한꺼번에 다시 연결
- **수업별 곡 목록 저장** (브라우저 IndexedDB), 곡별 볼륨·시작/끝 위치·전환 시간·반복
- **수업 모드** — 큰 버튼 전체 화면, 재생 중 화면 꺼짐 방지

## 단축키
| 키 | 동작 |
|---|---|
| Space | 재생·멈춤 (부드럽게) |
| N / → | 다음 곡 전환 |
| ← | 이전 곡 |
| F | 서서히 끄기 |
| B | 싱잉볼 |
| S | 사바아사나 타이머 |
| A | 배경 소리 켜기·끄기 |
| ↑ ↓ | 볼륨 |
| 1~4 | 큐로 이동 (비었으면 저장), Shift+숫자 = 다시 저장 |
| Z | 수업 모드 |

## 참고
- 곡은 사용하는 브라우저(기기)마다 따로 저장됩니다. 서버로 전송되지 않습니다. 기기를 옮길 때는 💾 백업 파일을 쓰세요.
- 권장: Chrome / Edge 최신 버전, 아이폰 Safari(iOS 17+), 안드로이드 Chrome. 홈 화면에 추가하면 앱처럼 동작(PWA).
